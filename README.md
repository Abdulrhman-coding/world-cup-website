# ⚽ World Cup 2026 — Luxury Hospitality Website

> A premium, white-themed promotional website for Saudi cafes, restaurants, and lounges during the FIFA World Cup 2026 season (June–July 2026).

---

## 🏆 Project Overview

This website is designed to help **Saudi hospitality businesses** (cafes, restaurants, and lounges) attract more bookings and create premium match-night experiences during the FIFA World Cup 2026 season.

The design aesthetic is **luxury white** — clean, modern, conversion-focused, with subtle football-event energy woven throughout.

---

## ✨ Key Features

- **Hero Section** — Premium headline with animated stadium-light background, two conversion CTAs
- **Match Viewing Experience** — Venue highlight with large screens, seating, and atmosphere details
- **Why Choose Us** — Premium USP cards: service, atmosphere, food, and convenience
- **Food & Drinks Showcase** — Elegant menu cards with hover effects
- **Booking / Reservation CTA** — WhatsApp button, phone booking, urgency messaging
- **Match-Night Offers** — Group packages, VIP deals, combo promotions
- **Venue Gallery** — Premium image grid with overlay effects
- **Testimonials** — Clean modern review cards
- **Contact Section** — WhatsApp, phone, location, hours, social links
- **Footer** — Minimal, premium brand footer

## 📱 Technical Specs

- **Pure HTML5, CSS3, Vanilla JavaScript** — no frameworks, no dependencies
- **Fully Responsive** — mobile-first layout
- **Scroll Animations** — Intersection Observer API
- **Smooth Hover Effects** — CSS transitions
- **Sticky Mobile Booking Button** — always-visible WhatsApp CTA on mobile
- **SEO-Friendly** — semantic HTML, meta tags, Open Graph
- **Arabic-Ready** — RTL-compatible layout structure, Arabic font support
- **Fast Loading** — no external JS libraries

## 🚀 Setup & Usage

1. **Clone the repo**
   ```bash
   git clone https://github.com/Abdulrhman-coding/world-cup-website.git
   ```

2. **Open locally**
   ```bash
   cd world-cup-website
   open index.html
   ```
   Or simply drag `index.html` into your browser.

3. **Customize for your brand**
   - Replace venue name, logo, phone number, WhatsApp link
   - Update menu items in the food section
   - Swap gallery images with real venue photos
   - Update match schedule dates
   - Adjust colors in `style.css` CSS variables
